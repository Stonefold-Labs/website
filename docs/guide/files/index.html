Files

Documents kept encrypted, with scanning on the iPhone.

  • Looking at a file
  • Reminders before a file expires
  • Deleting in Files

What Files is

A private place for your documents, inside Stonefold.

Files keeps the documents you’d rather not lose: IDs, insurance, receipts, warranties and manuals. It is a place inside the app, not a cloud drive.

How do I turn it on?

Welcome offers Files, and it is off until you choose it. You can turn it on any time in Settings ▸ Features: Sections. Once Files is kept, the app’s lock is on, as it is for the notes.

How is it kept?

  • Files keeps a file of its own, encrypted, opened by the same unlock as the notes and the budget.
  • Each document is sealed by itself, with a key of its own, inside that encrypted storage on this device.
  • Nothing in Files is copied into your other files, a setting, an alert or a log.

The recovery sheet covers Files too, with a code of its own. Backups of Files hold the list of your documents and what opens them, not a second copy of each document.

Bringing files in

Drag them in, add them, send them from another app, or scan paper with the camera.

On the Mac

  • Drag files from the Finder onto the list, or onto a folder in the sidebar.
  • Or choose Files ▸ Add Files… (⌘N).
  • A folder dragged in comes in as a folder, with what is in it.

On the iPhone

  • Tap Add, then Add Files to choose files.
  • Or tap Add, then Scan Document to scan pages with the camera. A scan is kept as one PDF. The first time you scan, the system asks whether the app may use the camera. The camera is used for nothing else.
  • From another app, choose this app among the places a file can be sent, and the file comes into Files. The system copies it into the app’s own folder, where it waits, unreadable while the iPhone is locked and left out of its backups, until it is sealed into Files and that copy is deleted.

What can come in

Any kind of file. Each file is sealed by itself, with a key of its own, inside the app’s encrypted storage on this device. A file may be up to 2 GB.

Folders, names and details

Keep documents in folders, and say what each one is and when it expires.

Folders and names

  • On the Mac, New Folder… (⇧⌘N) makes a folder inside the one on screen. Right-click a file or a folder to rename it, move it or delete it. Rename… is ⌘R.
  • On the iPhone, Add ▸ New Folder makes a folder inside the one on screen. Swipe a row to delete it. A file’s own screen has Move To and Rename….

A folder can’t go into itself or into a folder inside it. Deleting a folder sends what is in it to Recently Deleted with it.

Details

A file’s details say what kind it is: ID, Insurance, Receipt, Warranty, Manual or Other. If you set them, they also say the day it was purchased and the day it expires. A file within 30 days of expiring says “Expires soon”.

Finding a file

Search by name, by the words inside, and sort the list.

Search

Search finds a file by its name, and by the words inside it: a PDF’s own text, a text file’s words, and, with Find Words in Pictures and Scans on, the words in pictures and scans. Every word you type must be in the name or in the words found. Capitals and accents don’t matter.

Words in pictures

Words in pictures are read on this device by Apple’s Vision framework, with no language model. Nothing is sent anywhere. The switch is in Settings ▸ Features: Files, and starts off. When you turn it on, it looks through the files it hasn’t looked at yet, and says so under the switch.

Sorting

  • On the Mac, click a heading of the list to sort by it. Click it again to turn the order round. You can sort by name, date added, kind, expiry date or size.
  • On the iPhone, Add ▸ Sort By changes the order of the list.

Folders come first.

Looking at a file

A preview that is drawn from memory, so no copy is written anywhere.

A PDF, a picture or a text file is shown in its details, drawn from memory: no copy is written anywhere to show it. The app’s own preview opens a file of up to 200 MB. A larger one offers Save a Copy… instead.

Another kind of file shows its name, kind and size, and can be saved out with Save a Copy… and opened in another app.

Save a Copy…

Save a Copy… writes the file as it is into a folder you choose. It is then outside the app, and no longer sealed.

Reminders before a file expires

An alert before a document runs out, that never names the file.

How do I turn it on?

In Settings ▸ Features: Files, turn on Remind Me Before a File Expires. It starts off. An alert then comes at 9:00 a week, 30 days or 60 days before a file’s Expires day. You choose which. It starts at 30 days.

What the alert says

The alert says only “A document expires soon.” It never names the file, because what an alert says shows on the Lock Screen. Nothing about a file goes into an alert or into your other files.

Deleting in Files

Deleted files wait in Files’ own Recently Deleted.

A deleted file or folder goes to Files’ Recently Deleted. Choose it there to put it back. A folder comes back with what was deleted with it.

Wiping

Delete Now… and Empty Recently Deleted… clear it for good: its details and its key are wiped and its sealed contents deleted. Backups made before then still hold its listing and the words found in it until they age out, never its contents.

Taking files with you

Save a Copy… writes one file out as it is. Export Everything copies every file not in Recently Deleted out as it is, in its folders, into a folder called Files. Nothing in that folder is encrypted. See Leaving with your things.
